Getting help with an app

So we can help quickly, please include:

  • Which app and version (in the app: Settings, then About)
  • Your device, for example a Windows 11 PC or an Android phone
  • What you were doing and what happened, with a screenshot if you can

Please don't send us data files, backups, staff details or other personal information. We'll never ask for them; a description and a screenshot with personal details hidden is enough.
