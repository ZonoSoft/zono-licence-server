# zonosoft.co.uk website

Static pages served by Caddy on the licence server (`deploy/install.sh` copies this folder to `/opt/zono-licence/site`).
`/portal`, `/api/*` and `/downloads/*` go to the licence server; installers are uploaded on the admin page
(https://licence.zonosoft.co.uk/admin → Downloads on the website).

Fonts: Archivo and Atkinson Hyperlegible (SIL Open Font License, see `fonts/`), served from this site — nothing is
loaded from other companies.
